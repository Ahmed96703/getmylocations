## Writing rules (from this month's audits)

- Put the direct answer within the first two paragraphs.
- Cite a primary source for each number, or leave the number out.
- Generate any table of results from the site's own code, not by hand.
- Bump `modifiedDate` only for real content changes; the sitemap follows automatically.
