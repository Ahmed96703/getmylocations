How to look up who owns an IP

  • Type or paste the address. IPv4 (203.0.113.7) and IPv6 (2001:db8::1) both work. The tool starts with your own public IP, so it doubles as a “what is my IP” WHOIS check.
  • Read the network and IP range. Addresses are handed out in blocks, so the record covers a range, shown both as first–last address (the NetRange) and in CIDR form.
  • Check the contacts. The table lists the organizations attached to the record and their role: registrant, administrative, technical or abuse.

Whether you search for IP WHOIS, WHOIS IP, “who is” IP or ipwhois, it is the same lookup: the public registration record for an IP address.

Who hands out IP addresses

The global pool is managed by IANA, which gives large blocks to five regional internet registries (RIRs). They assign smaller blocks to internet providers, hosting companies and other organizations, and keep the public WHOIS record of who holds each one.

RegistryRegion it manages
African Network Information Centre (AFRINIC)The African continent
American Registry for Internet Numbers (ARIN)The United States, Canada, and many Caribbean and North Atlantic islands
Asia-Pacific Network Information Centre (APNIC)Asia, Australia, New Zealand and surrounding countries
Latin America and Caribbean Network Information Centre (LACNIC)Latin America and parts of the Caribbean
Réseaux IP Européens Network Coordination Centre (RIPE NCC)Europe, the Middle East and Central Asia

The tool asks rdap.org, which forwards the question to whichever registry holds the address, so you always get the authoritative record, whether it is an ARIN, RIPE, APNIC, LACNIC or AFRINIC WHOIS.

WHOIS lookup vs IP geolocation

A WHOIS lookup tells you who an address is registered to. IP geolocation estimates where it is used. A large provider may register all its blocks at its head office in one city while customers use them across the country, so the two can differ. Use both together: WHOIS for ownership and abuse reports, IP Location for the likely city and region.

What WHOIS can and cannot tell you

A WHOIS record is about the block, not a person. For a home or mobile connection it names the internet provider; for a server it names the hosting company or, sometimes, the business that rents a large block. It never shows a customer’s name or street address.

To see the network an address is routed through, use the ASN lookup; to check whether it is listed for sending spam, use the IP blacklist checker; and for a domain name’s registration date, use the domain age checker.

Frequently asked questions

What does an IP WHOIS lookup show?

It shows the registration record for the block of addresses an IP belongs to: the organization it is assigned to, the IP range (NetRange) and CIDR, the country it was registered in, the regional registry that issued it, the dates it was registered and last changed, and the contacts, including where to report abuse.

How do I find out who owns an IP address?

Enter any valid IP address in the box and press Look up. The network name and the contacts table show the organization the address is registered to, usually an internet provider, hosting company or large business.

Is this IP WHOIS lookup free?

Yes. It is free with no signup and no limit, and it works for both IPv4 and IPv6 addresses.

What is my IP, and can I see its WHOIS?

The tool looks up your own public IP address as soon as the page opens, so the first result you see is your own WHOIS record: your internet provider, its IP range and the registry that issued it.

Does IP WHOIS show who is using the IP right now?

No. It shows the organization the addresses are registered to. Which of their customers used an address at a given moment is known only to that provider and is not public.

Is WHOIS the same as RDAP?

RDAP is the newer replacement for the old WHOIS protocol. It returns the same registration data in a structured format, over a normal web connection. All five regional registries run RDAP servers, and this tool reads them directly.

Is IP WHOIS the same as IP geolocation?

No. The WHOIS country is where the organization registered the block, often its head office. IP geolocation databases estimate where an address is actually used, which can be a different city or country. Use IP Location for the estimated location.

How do I report abuse from an IP address?

Send your report to the abuse contact shown in the results, with the date, time and time zone of the activity and any logs. The provider can match the time to the customer who used the address.
