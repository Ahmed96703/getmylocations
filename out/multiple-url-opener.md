## What is a multiple URL opener?

A multiple URL opener takes a list of web addresses and opens each one in its own browser tab, so you do not have to copy and paste them one by one. It is useful whenever you have a column of links in a spreadsheet, an email or a report and need to look at every page: checking a site after an update, reviewing search results or starting the day with the same set of dashboards.

## How to open many links at once

1.  Paste your list, one link per line. Spaces and commas also work as separators.
2.  Press **Open all**. If only one tab opens, allow pop-ups for this site and press it again.
3.  Or press **Open next** repeatedly to open them one by one; opened links turn grey.

## How your list is read

Each line, or each item separated by spaces or commas, is turned into a full address. These examples were run through the tool itself:

| You paste | Opens | Why |
| --- | --- | --- |
| example.com | https://example.com/ | https:// is added |
| www.wikipedia.org/wiki/Map | https://www.wikipedia.org/wiki/Map | Paths are kept |
| http://neverssl.com | http://neverssl.com/ | http:// is kept as typed |
| EXAMPLE.COM | Skipped | Same as example.com, so skipped as a duplicate |
| ftp://files.example.com | Skipped | Not a web address |
| localhost | Skipped | No dot, so not a public site |
| hello | Skipped | Plain words are ignored |

Duplicates are compared after this clean-up, so `example.com`, `https://example.com` and `EXAMPLE.COM` open only once.

## How to allow pop-ups so Open all works

Browsers let a page open only one tab per click unless you allow pop-ups for that site. You only need to do this once:

| Browser | How to allow pop-ups for this site |
| --- | --- |
| Chrome | Click the blocked pop-up icon at the right of the address bar, choose Always allow pop-ups and redirects, then Done |
| Edge | Click the blocked pop-up icon in the address bar and choose Always allow |
| Firefox | In the yellow bar that says pop-ups were blocked, click Options (or Preferences) › Allow pop-ups |
| Safari on Mac | Safari › Settings › Websites › Pop-up Windows, and set this site to Allow |
| Chrome on Android | Settings › Site settings › Pop-ups and redirects, and allow this site |
| Safari on iPhone and iPad | Settings › Safari (Settings › Apps › Safari on iOS 18 and later), turn off Block Pop-ups; or use Open next |

## Open all or Open next?

|  | Open all | Open next |
| --- | --- | --- |
| Tabs per click | Every link in the list | One |
| Needs pop-ups allowed | Yes, for more than one tab | No |
| Best for | Short lists you want side by side | Long lists, phones and tablets, or reviewing pages in order |
| Keeps your place | No | Yes: opened links turn grey |

Every open tab uses memory, so on a laptop or phone it is kinder to open a long list in batches of 10 to 20 and close each batch before the next.

## Frequently asked questions

Can I open the links in a private or incognito window?

Yes. Open this page in a private window first; links it opens stay in that window. Links opened from a normal window open in normal tabs.

How do I open the same set of links every day?

Paste them here once, open them all, then save them as a bookmarks folder. Chrome and Edge can then reopen the whole folder with right-click › Open all, and Firefox with Open All in Tabs. Chrome also has “Open a specific set of pages” under On startup in its settings.

Why does only one tab open?

Browsers allow one new tab per click to stop pop-up spam. Allow pop-ups for this site once (click the blocked pop-up icon in the address bar) and “Open all” will open the whole list. “Open next” always works without changing any settings.

How many links can I open?

There is no limit in the tool, but each tab uses memory. Opening more than 20 to 30 at once can slow a computer down; open large lists in batches.

Do I need to type https://?

No. Bare domains such as example.com get https:// added. Duplicates and anything that is not a web address are skipped.

Is my list saved?

No. The list stays in your browser tab and is gone when you close or reload the page.
